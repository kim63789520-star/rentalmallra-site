상담 신청

개인정보처리방침

다콩(이하 '회사')은 더리본상조 가전결합 상담 신청과 관련하여 「개인정보 보호법」에 따라 정보주체의 개인정보를 보호하고 고충을 원활하게 처리하기 위하여 다음과 같이 개인정보처리방침을 정하여 공개합니다.

1. 처리 목적

상담 신청 접수와 상담 연락, 그리고 자동 수집 정보(2항)는 부정 클릭 방지와 광고 효과 확인에만 이용하며, 다른 목적으로 이용하지 않습니다.

2. 처리 항목

  • 필수: 이름, 휴대폰번호
  • 신청 시 함께 기록: 관심 상품, 신청한 페이지 주소, 신청 시각
  • 방문 시 자동 수집: 접속 IP 주소, 방문 일시, 방문한 페이지 주소, 유입 경로(이전 페이지 주소·광고 클릭 정보), 브라우저 종류

3. 보유 기간

상담 신청 정보: 접수일로부터 90일 보관 후 파기
방문 시 자동 수집 정보: 기록일로부터 90일 보관 후 자동 삭제

4. 제3자 제공

정보주체의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우는 예외로 합니다.

5. 처리 위탁

상담 신청 내용의 전달·보관을 텔레그램 메신저에, 방문 기록의 보관을 구글 스프레드시트에(모두 국외 보관, 6항) 맡기는 것을 제외하고는 개인정보 처리 업무를 위탁하지 않습니다.

6. 개인정보 국외 이전(보관)

상담 신청을 접수하고 연락드리기 위해(계약 체결 전 요청에 따른 조치) 신청 내용을 아래와 같이 해외 메신저 서버에 전송·보관합니다.

  • 이전받는 자: Telegram Messenger Inc.(텔레그램 메신저 운영사), 연락처: 텔레그램 앱 설정 > 질문하기 (telegram.org/privacy)
  • 이전 국가: 영국령 버진아일랜드·아랍에미리트(텔레그램 그룹사와 공유될 수 있음, 텔레그램 개인정보처리방침 8.2항) 및 텔레그램 데이터센터가 있는 해외 국가(한국 이용자 데이터의 저장 국가는 공개되지 않음)
  • 이전 시기·방법: 상담 신청 즉시, 인터넷 암호화 통신(HTTPS)으로 전송
  • 이전 항목: 이름, 휴대폰번호, 관심 상품, 신청 페이지 주소, 신청 시각
  • 이전받는 자의 이용 목적: 메시지 전송·보관 (상담 담당자에게 신청 내용 전달)
  • 보유 기간: 접수일로부터 90일 보관 후 파기
  • 거부 방법과 효과: 텔레그램 전송을 원하지 않으면 온라인 신청 대신 전화·카카오톡으로 상담하실 수 있습니다.

방문 기록은 아래와 같이 해외 서버에 보관합니다.

  • 자동 수집 항목: 접속 IP 주소, 방문 일시, 방문한 페이지 주소, 유입 경로(이전 페이지 주소·광고 클릭 정보), 브라우저 종류
  • 이용 목적: 부정 클릭(같은 곳에서 광고를 반복해 누르는 행위) 방지와 광고 효과 확인
  • 보유 기간: 기록일로부터 90일 보관 후 자동 삭제
  • 이전받는 자·국가: Google LLC(구글 스프레드시트에 보관), 미국 · 이전 시기·방법: 방문 즉시 HTTPS로 전송
  • IP 주소 확인을 위해 방문 시 ipify(api.ipify.org) 서비스에 접속합니다. 이 서비스에는 다른 정보를 보내지 않습니다.

7. 파기 절차와 방법

접수일로부터 90일이 지나면 텔레그램 대화방의 해당 신청 메시지를 삭제하여 파기합니다. 방문 기록은 90일이 지나면 구글 스프레드시트에서 자동으로 삭제됩니다.

8. 정보주체의 권리

정보주체는 언제든지 개인정보 열람·정정·삭제·처리정지를 요구할 수 있습니다. 아래 개인정보보호책임자에게 전화나 이메일로 요청하시면 지체 없이 조치합니다.

9. 안전성 확보 조치

신청 내용은 암호화 통신(HTTPS)으로 전송됩니다.

10. 쿠키

회사는 이용자 정보를 저장하는 쿠키를 설치·운영하지 않습니다.
